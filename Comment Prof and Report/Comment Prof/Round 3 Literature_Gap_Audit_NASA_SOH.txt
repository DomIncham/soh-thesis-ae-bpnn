Basis: Round 2 Progress Report (Steps 1–18, 25 Sep 2026) and a literature search of 2022–2026 journal papers using the
NASA battery dataset.
Summary in one paragraph. Our lower scores are mainly caused by a stricter evaluation
protocol and different input features, not by a data-processing error. Almost every NASA
paper that reports R² > 0.95 uses at least one of: (a) a random or chronological split inside the
same battery; (b) inputs that are indirect capacity proxies (previous-cycle capacity, cycle index,
accumulated Ah, discharge duration); or (c) 34 NASA cells with R² pooled over many batteries.
Under a strict unseen-battery protocol with only B0005/06/07/18, recent 2026 papers report R² ≈
0.53–0.88 and RMSE ≈ 4–7 %SOH. Our TD-BPNN result (R² ≈ 0.85, RMSE 3.59 %SOH) is at
the same level or slightly better. However, R² = 0.85 is not yet a novelty claim: (1) the
time-domain features have not been audited for capacity proxies; (2) the final model may have
been trained on only two batteries; and (3) a 2026 paper has already combined EIS + discharge
features + cross-battery evaluation (Section 3).

in your thesis (Literature Review, Methodology, Results and Discussion chapters). Section 6
explains exactly where each part belongs. Before you cite any number, please open the full text

5. Question 3 — Recommended Next Steps for Don
A. Fix the evaluation protocol first (within 1 week; may improve scores without
changing the model)
(cid:127) Re-fit: after the inner validation selects the hyper-parameters, re-train on all three training
batteries before testing. Alternatively, make the inner loop a 3-fold LOBO. This should help the B0006
fold most.
(cid:127) Report R² in two ways: per-fold mean and pooled. Report RMSE in both %SOH and Ah, and add
MAPE. This allows a fair comparison with the literature.
(cid:127) Protocol-gap experiment: with the same features and the same model, run (i) a random split, (ii) a
chronological split within each battery, and (iii) nested LOBO. We expect (i) to reach R² > 0.97. This
directly shows that the gap is caused by the protocol, and it can become a full section of the thesis.
B. Target-proxy audit (the most important scientific question)
(cid:127) List every TD feature and label it safe or proxy. Proxies include discharge duration, end-of-discharge
time, ∫I dt (accumulated Ah), cycle index, and previous-cycle capacity.
(cid:127) Run three settings under the same nested LOBO × 3 seeds: TD-All, TD-Proxy-Free, and an
Oracle-proxy baseline (I × t only). The oracle should give R² ≈ 1 and explains where high published
scores come from.
C. Improve proxy-free accuracy (ordered by expected benefit / effort)
(cid:127) Use charging-segment features. All four batteries use the same charge protocol (CC 1.5 A → 4.2 V
→ CV), while their discharge cut-off voltages differ. Use CC-charge time in fixed voltage windows
(3.9–4.0 V, 4.0–4.1 V), CV-phase time, and IC-peak voltage/height. These features are naturally
aligned across batteries and are partial-window by design (the approach used in [9] and [10]).
(cid:127) Fixed voltage window for discharge features, e.g. 4.0 → 3.6 V (all batteries pass through it),
instead of whole-cycle minimum voltage or total time.
(cid:127) Self-referenced normalization: divide (or subtract) each feature by the value from the same
battery's first cycle. No label is needed at deployment, and it removes initial cell-to-cell offsets (e.g.
B0006 starts at 2.035 Ah; the others at about 1.86 Ah). Low cost, potentially large gain.
(cid:127) Monotonic / physical prior: predict the degradation increment ΔSOH and accumulate it (as in
EWDC [10]), or add a monotonicity penalty to the BPNN.
(cid:127) Window-length curve: plot RMSE versus window length (5/10/20/30 min, or ΔV = 0.1/0.2/0.3 V).
This answers “how little data is enough?” and is the key figure for a partial-cycle contribution.
D. Wider validation
(cid:127) Within NASA: add B0025–B0056 cells with similar conditions so that training grows from 3 to 10+
batteries, and show a learning curve of LOBO performance versus the number of training batteries.
(cid:127) Cross-dataset: develop and freeze the model on NASA, then test directly on CALCE CS2 (the dataset
used by EWDC, so results are comparable), and later Oxford if time allows.
E. Role of EIS and the autoencoder
(cid:127) Replace the 256-dim interpolated spectrum with a few scalars (NASA-provided Re and Rct, |Z| range,
arc height) and use them as auxiliary fusion features. Keep fusion in the main method only if it clearly
beats TD-only.
(cid:127) Move the AE to the ablation / negative-result section (AE-TD R² 0.43 vs TD 0.85). Do not keep the AE
just to match the old thesis title.
